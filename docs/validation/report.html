Findings in the original code

  • F1 · Static anisotropy counted twice. In macrospin/current.py, ku() returns the static K when flag2 (Ku(t)) is off, and solver.py adds it again through the AC anisotropy term along u_ani_AC, which defaults to the easy axis. The dynamics therefore use 2 Ku: the AFMR and Kittel frequencies match 2 Ku, not Ku. Either return 0 from ku() when flag2 is off, or document that the effective anisotropy is 2 Ku. The original code is not changed by SpinMate.
  • F2 · RK4 weight 0.166 instead of 1/6. solver.py RK4() uses 0.166 * h; 1/6 = 0.1667. The default integrator is Heun, so runs are not affected.
  • F3 · Thermal field direction. solver.py draws the thermal field direction from np.random.rand(3), which only has positive components; an isotropic field needs a normal distribution. It only matters with Temp_Ampl > 0.
