Engines as plug-ins

Built in · default

macrospin

  • Two coupled LLG equations, sublattices m₁ and m₂
  • Exchange, anisotropy, field, SOT, temperature, drives
  • Sweeps, continuation, combination of runs
  • Runs on any CPU in seconds

Plug-in · optional

mumax3

  • GPU micromagnetics of a ferromagnet on a grid
  • SpinMate lines become an .mx3 script, or bring your own
  • Run card shows the average ⟨m⟩(t)
  • Needs an NVIDIA GPU and MUMAX3_BIN

[project.entry-points."spinmate.engines"]

mumax3 = "spinmate_mumax3:Mumax3Engine"

One interface: parameter_schema, validate, run_command, outputs. mumax3 (GPL v3) runs as a separate program, so SpinMate stays MIT.

Cite mumax3: Vansteenkiste et al., AIP Advances 4, 107133 (2014)

14

Every engine implements the same interface and every run records which engine produced it. macrospin is built in and needs nothing else. mumax3 is installed as a Python plug-in that registers under the spinmate.engines entry point; the binary itself is not bundled and needs an NVIDIA GPU. Agents call list_engines and pass engine equals mumax3.
