Four engines, one interface

Built in · default

macrospin

  • Two coupled LLG equations, m₁ and m₂
  • Exchange, anisotropy, SOT, temperature
  • Sweeps and continuation
  • Runs on any CPU in seconds

Built in · 2D, 3D

mm2d · mm3d

  • SpinMate's own 2D and 3D micromagnetics
  • Skyrmions, spin waves, hopfions
  • Relaxation or LLG dynamics
  • No GPU, seconds per film

Plug-in · GPU

mumax3

  • GPU micromagnetics on a grid
  • SpinMate lines or an .mx3 script
  • Run card shows ⟨m⟩(t)
  • Needs NVIDIA GPU, MUMAX3_BIN

[project.entry-points."spinmate.engines"]

mumax3 = "spinmate_mumax3:Mumax3Engine"

One interface: parameter_schema, validate, run_command, outputs. mumax3 (GPL v3) runs as a separate program, so SpinMate stays MIT.

Cite mumax3: Vansteenkiste et al., AIP Advances 4, 107133 (2014)

14

Every engine implements the same interface and every run records which engine produced it. macrospin is built in and needs nothing else. mumax3 is installed as a Python plug-in that registers under the spinmate.engines entry point; the binary itself is not bundled and needs an NVIDIA GPU. mm2d, SpinMate's own 2D solver for skyrmions, is built in like macrospin. Agents call list_engines and pass engine equals mm2d or mumax3.
