Get started

Docker

cp .env.example .env

docker compose up --build

Add an Anthropic or OpenAI key to .env, then open localhost:8421.

Windows app

Download SpinMate-windows.zip from Releases, unzip and run SpinMate.exe. No Docker or Python needed; the catalog is SQLite.

First start

Athena asks your name and, optionally, your email for the PDF guide. No key yet? Run setup runs a preset directly.

github.com/Michaellianeris/sublattice-agent

Free and open source under the MIT license · the user guide is web/spinmate-guide.pdf

Three ways in: Docker, the Windows app, or plain uvicorn for development. On first start Athena asks for your name and, optionally, your email; with SMTP set in your own .env the welcome email brings the PDF guide. Without a key, Run setup still runs a simulation directly; only the chat needs a model.
