One question, one run

Behind one question

  1. The router picks a model for the chosen persona and request.
  2. The model calls validate_parameters, then start_simulation.
  3. The run queue starts the solver; the card shows live progress.
  4. wait_for_run returns the metrics, and the answer is written from them.
