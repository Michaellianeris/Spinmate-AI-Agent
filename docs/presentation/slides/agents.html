SpinMate is also an MCP server. Claude Code, Claude Desktop or any MCP agent can design, run and read simulations with the same tools, runs and queue as the web app. The web app itself now calls its tools through the same server. The physics guide, physics.md, is shared by the server prompts, the chat and the Claude Code subagent.
