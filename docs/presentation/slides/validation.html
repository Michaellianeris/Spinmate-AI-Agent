Each sublattice carries Ms/2, so the exchange field is 4|A0|/(Ms l²) and the anisotropy field 4Ku/Ms. The first run found four issues in macrospin; after the fixes, deterministic runs are bit-identical to version 1.0 on nine scenarios and the phase boundary is unchanged.
