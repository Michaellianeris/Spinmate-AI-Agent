The home page in dark theme. The left bar holds navigation: new conversation, history, the Runs panel, default parameters, Run setup without the assistant, the model gods and tools guide, and Settings for the theme and API keys. The message box takes a question or a .txt file, by keyboard or voice; under it you pick the persona, Fast or Deep, and see tokens and cost in euros. Find a skill gives ready questions, and Athena answers how-to questions at any time.
