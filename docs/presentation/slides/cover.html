SpinMate is an AI agent for spintronics simulation. The sphere shows the two sublattices: m1 precesses up to +z and m2 down to −z, the antiferromagnetic order the solver computes. You ask in plain language; SpinMate runs the original two-sublattice macrospin code and explains what the magnetization actually did.
