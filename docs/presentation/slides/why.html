What SpinMate gives you

By hand

  1. Edit the parameter file
  2. Run the solver and wait
  3. Write a plotting script
  4. Read the curves for switches and settling
  5. Collect parameters and figures into a write-up

With SpinMate

  1. One sentence, or the same .txt file
  2. Every value checked by the solver’s parser
  3. Run card with the sphere, curves and metrics
  4. Answer written from the computed metrics
  5. IEEE figure and PDF report on request

Same solver, same physics: the agent removes the steps around it, not the model.
