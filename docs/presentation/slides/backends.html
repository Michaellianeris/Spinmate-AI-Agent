The time step is adaptive (Dormand–Prince); the exchange of the cells sets it: 35 fs for 1 nm cells, 123 fs for 2 nm.

The micromagnetic engines now run on all the cores of the CPU or on an NVIDIA GPU. The physics of one cell is written once and compiled twice, by numba for the CPU and as CUDA kernels for the GPU, so the results are the same: the CPU code reproduces the reference fields to one part in a trillion. On two cores one time step of a 128 by 128 film is eight times faster, about a minute and a half per nanosecond. The time step stays adaptive; the exchange of the smallest cells sets it, so larger cells make long runs much cheaper.
