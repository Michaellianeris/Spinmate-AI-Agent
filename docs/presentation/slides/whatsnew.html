SpinMate · Version 2.0

3

Version 2.0 turns SpinMate from a standalone app into a reusable scientific capability. The physics engine becomes a Python package with no LLM inside, every agent reaches it through MCP, and the web app becomes one client among many. A validation suite checks the solver against analytic results, and engines are plug-ins.
