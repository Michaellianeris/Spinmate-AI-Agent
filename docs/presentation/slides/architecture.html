SpinMate

4

In version 2.0 every client goes through one MCP server. The web app keeps its provider-neutral agent loop and model router, but calls the tools through MCP like Claude Code or Claude Desktop. Below the server, spinmate-core holds the tools, the run queue, the catalog, figures and reports and the engine interface; it loads no LLM library.
