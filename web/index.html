Model gods

Four levels, one god each. Pick the level that matches the question: a quick check, an everyday run, or a careful analysis. Larger models usually cost more tokens and take longer to answer.

What the tools do

Left bar

New chat

Starts a fresh conversation. The current one is saved in the history first.

History

Lists your earlier chats with their runs and graphs. Click one to reopen it, or the cross to delete it. Every user has their own history.

Runs

Every run on the server, newest first. Search by id, label, #tag or parameter, filter by status, end state or starred, star runs and give them tags. Click a run to open its card. Tick 2–6 runs to Compare them in one chart and table, make a Figure for a paper, or a Report.

Default parameters

Edit the values Fast mode starts from: duration, Ms, exchange A0, anisotropy Ku, damping, temperature, SOT current, the initial state and one or two extra flags. They are saved in this browser and also sent to the assistant as the base of its runs. “Reset to built-in” brings back the originals.

Run setup

Starts a simulation yourself, without the assistant, so it uses no tokens. Fast has presets (AFM→FM, AFM→AFM, FM→AFM, FM→FM, FeRh heating), sliders, Check and Run. Deep is a text editor for the full parameter file with an examples menu, Check, Run and Save as file. The result appears in the chat.

Model gods

Opens a comparison of the four model levels (Hermes, Dionysus, Zeus, Apollo): what each one is good for, how fast and how deep it is, and which model it will use and what it falls back to. Each card has a button to choose it.

Physics validation

Shows that the solver passes its analytic checks (resonance frequencies, energy, damping, the AFM/FM boundary). Green when all cases pass; click for the full report and the phase diagram.

Connect to Claude

The commands that add SpinMate to Claude Code, Claude Desktop or any MCP agent, with copy buttons.

API key status

Green when a key is available (on the server or in this tab), amber when it is missing. Click it to open the settings.

M

Account

Shows who is signed in. Log out, then type another name in Athena’s window to log in. Each name keeps its own history and default parameters. There is no password.

Settings

Language (English US or UK, Greek, Spanish, German, Italian), colour theme (Light, Dark, Spin), your Anthropic, OpenAI and Gemini API keys, and the model each god uses (Auto by default). The keys stay in this browser tab and are only sent to your own server.

Under the message box

Attach

Adds a parameter .txt file to your message. Dragging a file onto the chat works too.

Model picker

Choose a god: Hermes (quick), Dionysus (balanced), Zeus (most capable) or Apollo (specialised). The exact Claude, OpenAI or Gemini model behind it is chosen automatically, and each god shows which one it will use. To fix a specific model, use Settings > Model behind each god.

Sweep or threshold form

Pick a parameter in convenient units, the range and the steps (or what to look for), and the duration. It writes a clear request with SI values and warns about unusual numbers.

⌨

Keyboard shortcuts

Ctrl+K new conversation, Ctrl+/ the Runs panel, Enter send, Shift+Enter new line, Esc close a window. On a Mac use Cmd.

tok

Usage and cost

Click the token counter for the tokens and the cost per day and per provider (Claude, OpenAI, Gemini) of every answer on this server.

2nd

Ask another god

Under an answer: sends the same question to another model level and shows both answers side by side.

F/D

Fast and Deep

Fast uses the default parameters and answers briefly. Deep works from the full parameters or your file, mentions the caveats that apply and analyses the dynamics in detail.

tok

Token counter

Tokens used in the current chat. Each answer also shows its own input and output tokens. Runs started from Run setup use none.

Send

Sends the message. Enter does the same.

In the chat
▶

Run cards

Every run shows its steps and then the full viewer: a dial with the +x and +z axes, the order before and after (for example AFM→FM), and a plot of m1, m2 and the Néel vector. Click the plot to move the playhead, drag to zoom, double-click to reset, and press Play to animate.

▸

Folded cards

Older run cards fold to one line (order, switches, settle time and the parameters you changed) when a new one appears. Click the line or the arrow to open it again; the star marks a run.

3D

3D sphere

Under the dial, switch to 3D sphere to see m₁ and m₂ on the unit sphere with their whole path. Drag to rotate; it follows the playhead and Play.

fig

Figure and Report

Figure… on a card or a comparison draws the quantities and time window you chose with matplotlib in Science, IEEE or Nature style, as PDF, SVG or PNG. Report writes a page with method, results, parameters, figures and parameter files; print it to PDF. The assistant can write the discussion for you.

→

Next steps and Run button

After an answer, two or three suggested follow-ups appear as buttons. Large requests (many runs or long runtimes) wait for your Run it button before anything starts. The token counter also shows an estimated cost in euro at list prices.

Export

Export CSV saves the whole trajectory (time, m1, m2, Néel vector). Export all data saves a zip with every output file of the run. Sweeps give a chart of mean |nz| against the swept parameter; click a point to open that run.
